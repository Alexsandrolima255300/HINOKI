# HINOKI — Agent Skills

Selected open-source Agent Skills for design engineering, animation, and Three.js.

## Installed in this project

- **Three.js Skills** by [cesartevisual](https://github.com/cesartevisual/threejs-skills) — MIT. Responsive 3D web projects, scenes/cameras, lighting, animation, particles, shaders, performance, accessibility, and visual testing.
- **Animation Skill** by [nguyenanhducdeveloper86](https://github.com/nguyenanhducdeveloper86/animation-skill) — MIT. Motion direction, GSAP/ScrollTrigger, web animation, and spatial WebGL.
- **Three.js Skills** by [full-stack-skills](https://github.com/full-stack-skills/threejs-skills) — Apache-2.0. Additional focused references for animation, lights, and post-processing.

## How to use

Before changing the interface, read the relevant `.agents/skills/<skill-name>/SKILL.md`. Keep HINOKI's existing visual identity and architecture. Prefer purposeful motion over decoration; use semantic HTML for content and actions; respect mobile performance, keyboard use, and `prefers-reduced-motion`. Do not claim browser/visual QA unless it was actually performed.

These are project-local instruction files. They do not add Three.js, GSAP, or other runtime dependencies by themselves.
