# HINOKI — Japanese Food Culture

Site demonstrativo de portfólio para uma marca fictícia de restaurante japonês.

## Identidade
- Vermelho vivo: #ED101A
- Preto: #080808
- Branco: #FFFFFF
- Tipografia de display provisória: Barlow Condensed. A fonte Kamirhi – Sans Japanese Style pode ser incorporada quando o arquivo licenciado da fonte estiver disponível.

## Funcionalidades
- Layout responsivo para desktop e celular
- Navegação por seções
- Cardápio com filtros por categoria
- Sacola interativa com quantidades e subtotal
- Fluxo de finalização em modo demonstrativo

## Executar
Abra o arquivo `index.html` no navegador. Não há dependências de build nem backend.

## Observação
Os produtos, preços e imagens são conteúdo ilustrativo para o portfólio. Endereço, canais de atendimento, entrega e pagamento ainda não foram configurados.
